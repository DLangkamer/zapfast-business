# ZapFast Business 0.19.6

Esta versão traz o recurso completo de **Anti-Delete (Anti-Revoke)**, preservando mensagens apagadas pelo remetente, além da nova arquitetura integrada de **Servidor Docker Multi-Contas com Painel Web**, controle de permissões por WhatsApp e auto-discovery na rede local para o app Desktop.

## Novidades

### 🛡️ Anti-Delete / Anti-Revoke Nativo (SQLCipher)
- **Preservação Integral de Mensagens Apagadas**: Quando um contato apaga uma mensagem para todos no WhatsApp (`Type::REVOKE`), o ZapFast **não exclui** o conteúdo do banco de dados local ou do servidor.
- **Identificação Visual Transparente**: A mensagem é mantida intacta e ganha um aviso no topo do balão com o ícone `🚫 Esta mensagem foi apagada` e um indicador visual discreto junto ao horário, permitindo ler o texto original, escutar áudios ou ver mídias enviadas mesmo após terem sido apagadas.

### 🐳 Servidor Docker Multi-Contas (`zapfast-server`)
- **Implantação Simples via Docker Compose**: Execute o ZapFast como serviço headless em containers Docker com persistência total em volume (`/app/data`).
- **Painel Web Administrativo Embutido (Porta 8080)**:
  - Interface moderna com tema dark glassmorphism e responsiva.
  - **Conectar Contas de WhatsApp Separadamente**: Crie instâncias independentes (ex: `vendas`, `suporte`) e escaneie o **QR Code gerado ao vivo na tela** com a câmera do celular.
  - **Criação de Usuários e Gestão de Acessos**: Cadastre operadores com login e senha para acesso ao sistema.
  - **Permissões Granulares por WhatsApp**: Defina individualmente quais contas de WhatsApp cada atendente pode visualizar e operar, isolando o atendimento por setor.
- **Descoberta Automática na Rede Local (LAN Auto-Discovery)**: Beacon UDP na porta `47120` que responde a buscas na rede local.
- **WebSocket Gateway em Tempo Real**: Sincronização instantânea bidirecional de mensagens, status de conexão e comandos.

### 💻 Conexão ao Servidor Docker no App Desktop
- **Modo Duplo**: Mantenha o uso Standalone tradicional (WhatsApp Web direto no PC) ou conecte-se a um servidor ZapFast na rede local/nuvem.
- **Busca Automática na Rede Local**: Botão dedicado `🔍 Buscar Servidores na Rede Local` na tela de login para localizar containers Docker na rede Wi-Fi/cabeada e preencher o endereço com 1 clique.
- **Login de Operador**: Autentique-se com seu usuário e senha do servidor, acessando exatamente as contas de WhatsApp atribuídas à sua permissão.

## Instalação e atualização

Baixe o instalador `zapfast-business-v0.19.6-x86_64-pc-windows-msvc-setup.exe` ou o pacote portátil nos arquivos desta release. Quem já usa o ZapFast Business pode abrir **Settings → About → Check for updates now**.

Para rodar o servidor Docker:
```bash
docker compose up -d --build
```
Acesse `http://localhost:8080` com as credenciais padrão `admin` / `admin123`.

ZapFast Business é um fork independente do [ZapFast](https://github.com/crmne/zapfast).
