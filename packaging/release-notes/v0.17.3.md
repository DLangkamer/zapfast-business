# ZapFast Business 0.17.3

This release adds the first advanced messaging controls for the independent
ZapFast Business fork.

- Optional **Mark chats as read when opened** privacy setting. When disabled,
  opening, replying in, or recording audio for a direct chat or group keeps it
  unread until **Mark as read** is chosen.
- Scheduled text messages for direct chats and groups from the composer's `+`
  menu, including replies and mentions.
- Scheduled content is stored in the encrypted Business archive and is sent
  through the existing message path while the app is running and connected.

This is the first scheduling phase. It does not yet include a schedule manager,
automatic retry controls, or broadcast lists. No messages are sent during
installation or update.

The Windows installer continues to use the separate **ZapFast Business**
installation folder, profile, credentials, shortcuts, updater identity and
uninstaller.
