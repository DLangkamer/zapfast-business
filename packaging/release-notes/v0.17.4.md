# ZapFast Business 0.17.4

This maintenance release makes update checks predictable and visible.

- Adds **Check for updates now** to Settings, bypassing the daily timer.
- Manual checks confirm when the app is current and display network or GitHub
  errors instead of hiding them in debug logs.
- Daily background checks remain quiet and continue to use only the signed
  ZapFast Business release channel.

Users on 0.17.2 or 0.17.3 can install this release once from GitHub. Future
checks can then be forced directly from Settings.
